# Security test vectors

`vault-format-v1/empty-vault-v1.sha256` commits to the complete deterministic
empty-vault header and encrypted-manifest envelope generated by the issue #10
test fixture. The fixture uses:

- the disposable password `vector password`;
- timestamp `1700000000000`;
- deterministic test-only entropy bytes beginning at `01` and incrementing for
  every requested byte;
- an unambiguous SHA-256 transcript of
  `u64be(header_length) || header || u64be(manifest_length) || manifest`.

The deterministic entropy source is compiled only in the core test module.
Production creation always calls the operating-system CSPRNG.
